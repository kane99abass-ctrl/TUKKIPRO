# Directives (Couche 1 : Quoi faire)

Ce dossier contient les Procédures Opérationnelles Standard (SOP) au format Markdown.

## Structure recommandée pour une directive :

1. **Objectif** : Que doit accomplir cette directive ?
2. **Entrées requises** : Fichiers, paramètres, identifiants ou arguments nécessaires.
3. **Scripts d'exécution** : Outils dans `execution/` à invoquer et dans quel ordre.
4. **Sorties attendues** : Fichiers intermédiaires (dans `tmp/`) ou livrables cloud (Google Sheets, etc.).
5. **Gestion des erreurs et cas limites** : Comment réagir aux échecs ou limites API.
