# Exécution (Couche 3 : Faire le travail)

Ce dossier contient les scripts Python déterministes et autonomes.

## Bonnes pratiques :
- Déterministes, fiables et bien commentés.
- Utilisent les variables d'environnement définies dans `.env` (via `python-dotenv`).
- Écrivent les données intermédiaires dans `tmp/`.
- Testables unitairement en ligne de commande.
